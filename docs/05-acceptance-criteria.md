# 验收标准文档 V1.0

所有指标为内部验收目标,**不得直接写入面向消费者的绝对准确率宣传**。
指标计算口径与埋点对应关系见 `08-analytics-plan.md`;测量方法见 `06-test-plan.md`。

| 指标 | 目标 | 测量口径 |

| BLE 首次连接成功率 | ≥98% | `device_connect_result` 事件,首次绑定场景 |

## 5. 阶段退出标准(Gate)

### 阶段0(第 1—2 周)协议验证
iOS 与 Android 均可发现设备、读取文件、下载完整文件并校验;固件团队确认可修改协议;协议无不可控授权问题。**不满足暂停全面研发。**

### 阶段1(第 3—4 周)基础框架
双平台登录成功;自动化构建成功;测试环境可用;App 可远程配置功能开关。

### 阶段2(第 5—8 周)设备连接与同步
设备连接成功率 ≥95%;1 小时音频稳定同步;切后台后队列可恢复;重复同步率 0;校验失败自动重试。

### 阶段3(第 9—12 周)云端上传与转写 → 内部 MVP
端到端"录音机→App→云端→转写结果"贯通;60 分钟录音 P95 ≤8 分钟返回;任务失败可重执行;同一文件不重复收费。

### 阶段4(第 13—16 周)摘要/编辑/导出 → Alpha
摘要结论可定位原录音;说话人改名全篇一致;导出格式正常;删除后云端、缓存、搜索索引三处同步删除。

### 阶段5(第 17—20 周)会员/OTA/合规
订单验证、退款同步、恢复购买、兑换码全通;OTA 失败恢复验证;App 内注销 + 网页删除入口上线;隐私标签与 Data Safety 完成。

### 阶段6(第 21—24 周)Beta 退出标准
Crash-free Session ≥99.7%;转写成功率 ≥99%;上传成功率 ≥99.5%;无数据串号;无重复扣分钟;无严重 OTA 事故;P0 清零;P1 有明确处理计划。Beta 规模:50—100 种子用户(中文 ≥20、英语 ≥20、阿语 ≥10),累积 1000 小时真实录音任务。

### 阶段7(第 25—26 周)发布
分阶段放量 5% → 20% → 50% → 100%,每阶段观察 24—48 小时,回滚预案就绪。

## 7. 成本验收

从第一天建立单次任务成本账本:
`单次任务成本 = ASR分钟成本 + 说话人分离成本 + LLM Token成本 + 音频存储成本 + 下载流量成本 + 支付渠道成本`
管理后台 `/admin/costs` 可按天/供应商/任务类型出数;上线前完成三档音频时长(10/60/180 分钟)的成本实测。
