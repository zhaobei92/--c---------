## 1. 产品定位

连接 AI 录音硬件的双平台 App,完成:**录音 → 同步 → 上传 → 转写 → 说话人区分 → 摘要 → 待办 → 编辑 → 导出 → 搜索问答** 的完整闭环,并建立可运营的会员商业系统与录音合规能力。

核心体验目标:**用户无需理解蓝牙和 Wi-Fi,在两三步内完成连接、同步和转写。**

## 5. V1 明确不做(负范围,写入承诺边界)

1. **不做系统级手机通话录音**。电话录音由硬件通过拾振/骨传导/外部麦克风完成,App 只同步文件。
2. **不承诺 iOS 锁屏后持续高速同步**。后台维持设备状态与传输队列,回前台自动续传;大文件同步提示保持前台;Android 用前台服务支持更长同步。
3. **不做"100+ 语言全部高精度"的营销承诺**。仅对 zh/en/ar 建立测试集与验收标准。
4. **不做用户声纹身份识别**。只区分 Speaker,不自动关联真实身份;用户可手工改名。
5. **不做无限转写**。所有套餐有分钟数、并发数、存储量与 AI 问答次数限制。

## 6. 核心用户流程

### 6.1 首次连接(≤3 步)
开机设备 → App 首页"添加设备"(BLE 扫描自动出现)→ 点击绑定(读 SN/型号/固件,写入绑定关系)→ 完成,显示设备状态卡。

### 6.2 同步与转写(闭环主流程)
BLE 发现设备 → 校验绑定 → 拉取设备文件索引 → 与本地库对比标记"新文件" → 用户点同步 → 设备开临时 Wi-Fi → App 申请加入设备网络(iOS: NEHotspotConfiguration;Android: Wi-Fi Direct/局部热点)→ 分片拉取(每 4—8MB 存检查点)→ SHA-256 校验 → 写本地记录 → 手机恢复互联网 → 分片上传云端 → 提交 AI 任务 → 转写/分离/摘要 → 推送"转写完成" → 按用户设置删除设备原文件。

必须处理的异常(逐条为测试用例,见 `06-test-plan.md` §4):App 切后台、拒绝附近设备权限、拒绝加入 Wi-Fi、电话打断、设备低电、手机低电、网络切换、下载中 App 被杀、文件被设备删除、同一文件重复同步、文件时间错误、文件损坏、设备被另一台手机连接、协议版本不一致。

### 6.3 摘要与溯源
每条关键结论/待办必须关联原文时间戳,例:

> 客户要求8月15日前提供报价。 来源:00:32:18—00:32:47

低置信度内容标记;不自动生成金额、日期、人名的"确定值";关键内容要求用户确认。

### 6.4 翻译视图
原文 / 中译 / 英译 / 阿译 / 对照。首版不修改原始转写,只生成独立翻译层。

## 7. 多语言与 RTL

- App 界面:中文、英文、阿拉伯语;阿语全局 RTL 布局(导航、列表、播放器、时间轴镜像)。
- 转写:zh、en、ar 词/句级时间戳与标点;分段(5—20 秒)语言识别,不强迫用户整段选单一语言。

## 8. 商业化

- 免费分钟额度(注册即送,月度重置)。
- 月度会员 / 年度会员 / 单独分钟包;硬件激活赠送会员;邀请码与兑换码。
- 苹果 StoreKit 2 与 Google Play Billing 应用内支付,服务端订单验证,权益跨设备/跨平台同步。
- 扣费顺序与流水:全部经 `usage_ledger`(见 `02-architecture.md` §7),退款回收、过期、续费、恢复购买齐备。
- AI 成本账本从第一天建立:单次任务成本 = ASR 分钟 + 说话人分离 + LLM Token + 存储 + 下载流量 + 支付渠道。

## 9. 合规(V1 必含)

- 明显录音状态提示;首次录音合规说明;用户确认已取得必要同意(记 consent_logs)。
- 音频保存期限设置、一键删除音频、一键导出个人数据、App 内注销、网页端删除入口。
- 操作与同意日志、数据存储区域选择、服务端访问审计。
- **禁止静默/隐藏录音与默认全天候录音模式**(UAE 等法域对私人场所与通话的未授权记录有刑事风险);UAE、美国、欧盟分别做法律审查。
- Apple 要求 App 内账户删除;Google 要求 App 内删除路径 + 公开网页删除入口;隐私标签与 Data Safety 如实填写。

## 11. 审核可用性(App Store / Google Play)

审核人员不持有硬件,App 必须提供:手机录音功能、内置演示录音、Demo Mode(模拟设备连接全流程)、审核账号、完整审核操作说明。Demo Mode 复用 `mock_device/` 协议实现。

## 12. 成功指标(上线 3 个月)

硬件激活率 ≥75%;激活后首次同步率 ≥70%;首次转写完成率 ≥65%;D7 留存 ≥30%;付费转化 ≥5%;转写结果编辑率持续监控;单用户 AI 毛利必须为正。
