# 测试计划 V1.0

## 1. 测试分层

| 层 | 范围 | 工具 | 执行时机 |
|---|---|---|---|
| 单元测试 | 服务端业务逻辑(状态机、权益扣减、上传合并)、Flutter 业务层 | pytest / flutter test | 每次 PR(CI 阻断) |
| 契约测试 | App ↔ 服务端 API;App ↔ 设备协议(先对 mock_device) | pytest + OpenAPI schema / mock_device 测试套件 | 每次 PR |
| 集成测试 | 上传→任务→转写→摘要 端到端(mock ASR) | pytest + docker compose | 每日 |
| 真机测试 | BLE、Wi-Fi 传输、OTA、权限、后台 | 真机矩阵(见 §5),**禁止只用云手机** | 阶段2 起每周 |
| 回归测试 | P0 全功能用例集 | 手工 + Maestro/Patrol 自动化 | 每个版本 |
| 专项测试 | 安全、压力、RTL、弱网、低电量 | 见 §6 | 阶段6 |

## 2. 单元测试基线(已在仓库落地)

- `server/tests/test_job_state_machine.py`:全部合法迁移、非法迁移拒绝、重试计数、终态锁定。
- `server/tests/test_entitlement_service.py`:扣费顺序(free_monthly→gift→member→purchased)、跨桶拆分扣减、余额不足拒绝、退款冲正、幂等(同 job 不重复扣)、过期桶跳过。
- `server/tests/test_upload_service.py`:init 去重、分片登记幂等、缺片拒绝合并、整体 hash 不一致拒绝。
- `mock_device/tests/`:BLE 状态机命令、文件索引、Range 断点续传、SHA-256 校验、传输中断恢复。

## 3. 功能测试范围(阶段6 全量)

功能、回归、连接稳定性、文件传输、权限拒绝、网络切换、低电量、低存储、App 崩溃恢复、OTA 中断、订单异常、退款、账户删除、阿拉伯语 RTL、安全测试、服务端压力测试、数据隔离测试。

## 4. 同步异常用例集(每条必须有自动化或手工用例编号)

| 编号 | 场景 | 期望行为 |
|---|---|---|
| SYNC-01 | App 切入后台 | 队列持久化,回前台自动续传 |
| SYNC-02 | 拒绝附近设备权限 | 引导页解释 + 系统设置跳转,不崩溃 |
| SYNC-03 | 拒绝加入设备 Wi-Fi | 回退 BLE 状态,提示重试 |
| SYNC-04 | 电话打断 | 传输暂停,通话结束续传 |
| SYNC-05 | 设备低电 | 提示充电,禁止发起 OTA |
| SYNC-06 | 手机低电 | 提示,允许用户选择继续 |
| SYNC-07 | 网络切换(Wi-Fi↔蜂窝) | 上传队列自动恢复,遵守"仅 Wi-Fi 上传"设置 |
| SYNC-08 | 下载一半 App 被杀 | 检查点续传,不产生半文件入库 |
| SYNC-09 | 文件被设备删除 | 索引对比标记失效,提示用户 |
| SYNC-10 | 同一文件重复同步 | (sn, file_id, sha256) 判重,重复率 0 |
| SYNC-11 | 文件时间错误 | 以设备 RTC + 同步时间修正策略处理并标记 |
| SYNC-12 | 文件损坏 | Hash 不一致自动重试,超限报 DEV_1204 |
| SYNC-13 | 设备被另一台手机连接 | 明确占用提示,不出现双写 |
| SYNC-14 | 固件协议版本不一致 | 版本协商,提示升级 App 或固件 |

## 5. 真机设备矩阵

**iOS**:当前主流 iPhone;较老 iPhone;当前系统版本 + 前两个主要版本;不同存储容量;不同运营商。
**Android(必须覆盖)**:Samsung、Google Pixel、Xiaomi/Redmi、OPPO、vivo、Honor、OnePlus。
BLE 与设备 Wi-Fi 传输必须真机测试。

## 6. 专项测试

- **安全**:鉴权绕过、越权(横向访问他人 recording/order)、上传预签名 URL 滥用、JWT 过期与轮换、兑换码爆破限流、依赖漏洞扫描;发布前一次外部渗透测试。
- **压力**:上传并发、任务队列积压恢复、60 分钟音频 P95 处理时长在 3× 峰值负载下仍达标。
- **RTL**:阿语全页面截图对比、时间轴/播放器/滑块镜像、混排文本(阿+英+数字)。
- **弱网**:2G/3G 模拟、50% 丢包、DNS 失败、上传中断恢复。
- **数据隔离**:多账号并发操作,校验无串号(自动化断言 user_id 隔离)。
- **计费**:重复点击购买、验证重放、退款后余额冲正、跨平台恢复购买。

## 7. Beta 计划(阶段6)

iOS TestFlight + Google Play Closed Testing;50—100 名种子用户(中文 ≥20、英语 ≥20、阿语 ≥10);累积 1000 小时真实录音任务;每周崩溃与错误码触发率复盘。

## 8. 审核测试(阶段7 前)

审核账号可用;Demo Mode 全流程可走通(无硬件);内置演示录音可转写;IAP 沙箱购买/恢复;账户删除入口(App 内 + 网页)可达。

## 9. 缺陷管理

P0:阻断主流程/资损/数据泄露 — 24h 内修复,清零后才能发版。
P1:主要功能受损有绕行 — 发版前有明确处理计划。
P2/P3:排期修复。
所有线上缺陷回填自动化用例。
